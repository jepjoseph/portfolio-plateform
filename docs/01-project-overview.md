# Portfolio Platform — Project Overview

## 1. Project Name

Portfolio Platform

## 2. Project Description

Portfolio Platform is a full-stack web application that allows users to create,
manage, and publish professional portfolios.

Users will be able to create an account, manage their professional information,
projects, experience, education, skills, and other portfolio content through a
professional dashboard.

Each user will receive a unique public portfolio URL.

Example:

https://yourplatform.com/u/jeanjoseph56

## 3. Main Goal

The goal of the platform is to provide users with a centralized professional
portfolio that can be easily managed and shared with employers, recruiters,
clients, and other visitors.

## 4. Core Features

- Portfolio management
- Project management

- Profile management
- Public portfolio pages

## 5. Design Direction

The application will use a dark-first futuristic professional interface.

The design will include:

- Dark-first interface
- Subtle gradients
- Glowing accent elements
- Glass/transparent cards
- Rounded UI components
- One primary accent color
- Responsive desktop, tablet, and mobile layouts
- Subtle animations
- Professional dashboard
- Modular portfolio sections

The application will follow a full-stack architecture:

User
↓
React Frontend
↓
Backend REST API
↓
Microsoft SQL Server

## 8. Public Portfolio URL

Each user will have a unique public portfolio URL based on their username.

Example:

https://yourplatform.com/u/jeanjoseph56

The public portfolio will be accessible without requiring the visitor to log
into the platform.
